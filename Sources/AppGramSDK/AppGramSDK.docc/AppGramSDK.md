# ``AppGramSDK``

AppGram iOS SDK for native SwiftUI integration of feedback, status pages, releases, and more.

## Overview

AppGramSDK is a comprehensive iOS SDK that enables seamless integration of AppGram features into your iOS applications. Built with SwiftUI, it provides native iOS components for user feedback, roadmaps, support tickets, status pages, release notes, and more.

### Key Features

- **Status Pages**: Real-time service status monitoring with auto-refresh
- **Release Notes**: Beautiful changelog and release announcements
- **Feedback Management**: Collect and manage user feature requests
- **Roadmap**: Share your product roadmap with users
- **Support Tickets**: Built-in customer support system
- **Help Center**: Knowledge base integration
- **Surveys**: In-app surveys and user feedback
- **Contact Forms**: Customizable contact forms
